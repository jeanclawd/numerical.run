# numerical.run apps

The same notebooks that run in this JupyterLite site, rendered as **apps** —
`nr_*` widgets live, figures inline, the whole document rerunning on every
interaction, exactly like numerical.run on the web. One RunMat WASM kernel, all
in your browser.

+++

### [Wave explorer →](?doc=../files/waves.ipynb)

Damped sine / cosine / pulse with live sliders.

+++

### [Mel spectrogram →](?doc=../files/signal.ipynb)

Chirp → FFT → mel filterbank → mel spectrogram, with a heatmap.

+++

### [kNN playground →](?doc=../files/knn.ipynb)

k-nearest-neighbours on two interleaved classes, sidebar of controls.

+++

### [Hello →](?doc=../files/hello.ipynb)

Inputs, session state, and a button — the basics.

+++

### [Damped sine (plain) →](?doc=../files/numerical-run.ipynb)

A plain-MATLAB notebook — compute and a figure, no widgets.
