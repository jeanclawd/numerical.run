Consolidating the editor & notebook

Two ways to remove the redundancy of showing the source twice. Open each, toggle to the app, and get a feel. Same document and kernel underneath.

OPTION 1

Notebook is the editor

Editable cells (Monaco per code cell) with output inline underneath — one surface that edits, runs, and shows results. App is a separate toggle.

＋ no duplicated render; most notebook-native
− biggest change; no single raw-source view
OPTION 2

Editor + App only

One Monaco editing the whole .nb.md, with the live App preview beside it. The read-only Notebook tab is gone.

＋ simplest; source stays one place
− no per-cell output attribution
