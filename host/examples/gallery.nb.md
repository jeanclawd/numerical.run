# numerical.run

Interactive notebooks that run entirely in your browser on the RunMat kernel — no
install, no server. Open one below, edit any cell and hit **Run**, or toggle
**App** to use it. Or **[start a blank notebook →](?new)**.

+++

### [Wave explorer →](?doc=examples/waves.nb.md)

[![Wave explorer](thumbs/waves.png)](?doc=examples/waves.nb.md)

Damped sine / cosine / pulse with live controls.

+++

### [Mel spectrogram →](?doc=examples/signal.nb.md)

[![Mel spectrogram](thumbs/signal.png)](?doc=examples/signal.nb.md)

Signal processing: chirp → FFT → mel filterbank → mel spectrogram.

+++

### [kNN playground →](?doc=examples/knn.nb.md)

[![kNN playground](thumbs/knn.png)](?doc=examples/knn.nb.md)

k-nearest-neighbours on two interleaved classes, with a sidebar of controls.

### [Hello →](?doc=examples/hello.nb.md)

### [The classic editor →](?doc=examples/classic-editor.nb.md)

[![The classic editor](thumbs/classic-editor.png)](?doc=examples/classic-editor.nb.md)
